# Contributing

Suggestions of new plugins are welcome.

## What goes into the list

* The plugin is published on the [JetBrains Marketplace](https://plugins.jetbrains.com/).
* It was updated in the last 2 years.
* It is useful to more than one small niche of users.
* It is not a feature that the IDEs already have and enable by default.

## How to add an entry

* Put the plugin into the section that fits it best, or into "Language specific" if it works only for one language or one IDE.
* The sections are not sorted alphabetically. Add a new plugin at the end of its section.
* Write one line with the plugin name linked to its Marketplace page, and optionally one short indented note under it that says what the plugin does, in the same form as the entries around it.

## How to propose a plugin

* Open a pull request that adds the entry to both `README.md` and `README_CN.md`. If you cannot write the Chinese text, say so in the pull request.
* Or open an issue with the plugin name, its Marketplace link and a sentence on why it is useful.
